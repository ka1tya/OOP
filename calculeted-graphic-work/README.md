# RasterEditor

Графічний редактор для обробки растрових зображень у форматі BMP 24 біти на піксел.

## Технології

- Python
- PySide6
- Pillow

## Можливості

- Відкриття BMP-зображень (24 біти на піксел) через стандартне діалогове вікно;
- Відображення зображення в головному вікні з прокруткою по горизонталі та вертикалі;
- Зміна світлоти та контрасту;
- Корекція компонент R, G, B;
- Вибір режиму обробки кнопкою на панелі інструментів;
- Підказки (Tooltips) для кожної кнопки панелі інструментів;
- Скидання налаштувань до початкових значень;
- Запис результату у BMP 24 біти через пункти "Записати" та "Записати як...".

## Модулі програми

| Модуль               | Призначення                                                                                   |
| -------------------- | --------------------------------------------------------------------------------------------- |
| `main.py`            | Точка входу, запуск програми                                                                  |
| `main_window.py`     | Головне вікно: меню "Файл", зв'язок між іншими модулями                                       |
| `toolbar.py`         | Модуль Toolbar: панель інструментів з кнопками файлів і режимів, панель повзунків для обробки |
| `image_viewer.py`    | Модуль Viewer: відображення зображення в головному вікні з прокруткою                         |
| `image_document.py`  | Модуль Files: читання та запис BMP-файлів, перевірка формату й глибини кольору                |
| `image_processor.py` | Обробка зображення: світлота, контраст, корекція R, G, B                                      |

## Встановлення та запуск

1. Клонувати репозиторій:

```bash
git clone <посилання-на-репозиторій>
```

2. Перейти до папки проєкту:

```bash
cd calculeted-graphic-work
```

3. Створити віртуальне середовище:

```bash
python -m venv .venv
```

4. Активувати віртуальне середовище

Для Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

5. Встановити необхідні залежності:

```bash
pip install -r requirements.txt
```

6. Перейти до папки редактора:

```bash
cd raster-editor
```

7. Запустити програму:

```bash
python src/main.py
```

## Використання програми

1. Запустити редактор;
2. Відкрити BMP-зображення через меню ЄФайл - Відкрити...Є або натиснути кнопку на панелі інструментів;
3. Вибрати режим кнопкою на панелі інструментів: "Світлота", "Контраст" або "Корекція RGB";
4. Змінити параметри повзунками на панелі "Обробка зображення" справа;
5. За потреби натиснути "Скинути налаштування", щоб повернути початковий вигляд зображення;
6. Записати результат:
   - "Записати" - у поточний файл;
   - "Записати як..." - у новий файл, вибраний через стандартне діалогове вікно.

## Тестування

Для запуску автоматичних тестів використовується бібліотека `unittest`. Команди виконуються з папки `raster-editor`.

Запуск усіх тестів:

```bash
python -m unittest discover -s tests -t . -v
```

Запуск тестів для обробки зображень:

```bash
python -m unittest tests.test_image_processor -v
```

Запуск тестів для роботи з файлами:

```bash
python -m unittest tests.test_image_document -v
```
